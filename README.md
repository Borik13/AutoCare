# AutoCare 1.0 — PWA

Початкова версія мобільного автомобільного журналу для iPhone.

## Що працює
- Світла та темна теми.
- Профіль Hyundai Sonata NF 2007 (початкові значення можна змінити).
- Облік ТО та ремонтів.
- Облік заправок і витрат.
- Нагадування за датою/пробігом (у цій версії відображаються в застосунку; push-сповіщення ще не підключені).
- Збереження даних у localStorage браузера.
- Експорт та імпорт резервної копії JSON.
- PWA manifest і service worker для офлайн-кешу.

## Важливі обмеження першої версії
- VIN-код можна зберегти, але автоматичний VIN-декодер та каталог OEM/аналогів ще не підключені. Для цього потрібен API постачальника даних і серверний проксі для захисту API-ключа.
- Дані зберігаються локально в браузері на одному пристрої. Синхронізація між пристроями та хмарна резервна копія ще не реалізовані.
- Для встановлення на iPhone як PWA сайт має бути розміщений на HTTPS-домені.

## Встановлення на iPhone
1. Розмістити вміст архіву на HTTPS-хостингу (наприклад, власний домен або статичний хостинг).
2. Відкрити адресу в Safari.
3. Натиснути «Поділитися» → «На початковий екран» → «Додати».

## Локальний перегляд
Для перевірки на комп'ютері запустити простий HTTP-сервер у цій папці, наприклад:
`python3 -m http.server 8000`
Потім відкрити `http://localhost:8000`. Для реального встановлення на iPhone потрібен HTTPS.
